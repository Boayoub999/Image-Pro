# Image Processing Lab 8: Edge Detection

This repository contains the implementation and analysis for **Lab 8**, focusing on fundamental edge detection techniques using Python and OpenCV.

---

## 📋 Overview
Edge detection is a foundational image processing operation used to identify points in a digital image where image brightness changes sharply or has discontinuities. This lab explores and compares three major edge detection operators:
1. **Sobel Edge Detector**
2. **Prewitt Edge Detector**
3. **Canny Edge Detector** (along with an analysis of its hysteresis thresholds).
